# Security policy

## Reporting a vulnerability

Send a private report to [the TAi maintainer](mailto:euan@mail.bnu.edu.cn). Include the TAi version, macOS version, expected security boundary, affected behavior and the smallest reproducible example. Use a synthetic browser Profile or a sample page when possible.

Keep vulnerability details out of public issues while the maintainer investigates. Share only the information needed to reproduce the problem. Leave credentials, connection files, cookies, saved passwords and real browsing data out of the report.

TAi is in early development. Reports against the latest available build help the maintainer reproduce the issue and identify the affected versions.

## Regular bugs

Use [GitHub Issues](https://github.com/EuanTop/tai-browser/issues) for ordinary bugs and feature requests.
